# Roadmap

Principle: build small, real things first; publish honest numbers; label goals as goals.

## Now (2026 Q4)
- [ ] Solar Nomad (Part 1): launch solar trailer rentals in northern Utah
- [ ] Wi-Fi sensing: bench test ESP32-S3 CSI (Espressif esp-csi) for presence/motion in a trailer
- [ ] Stargazing nights: confirm county permit path; run a first small test night
- [ ] Soul Resonance / Cymatica: browser prototype (tones, Chladni patterns) playable
- [ ] Lamplight Reading: single-page prototype with parent coaching cards + decodable stories

## Next (2027 H1)
- [ ] Wi-Fi sensing: record an open dataset across several trailers; decide on NSF SBIR Project Pitch with a university partner
- [ ] Citizen-science telescopes ("Star Fleet"): smart telescope on rentals; test contributing to an existing citizen-science network
- [ ] Bamboo/biomimetic housing: small test panels/columns and actual strength tests before any cost or strength claims
- [ ] Mycelium: small non-structural insulation panel trials

## Later (2027+)
- [ ] Prototype bamboo + hempcrete structure (goal, not yet costed by a builder)
- [ ] "Cyber RV" concept: integrate trailer solar/battery with EV charging (realistic: ~20 kWh bank ≈ 50–60 mi of Cybertruck range)
- [ ] Grants: USDA REAP (when window reopens), Western SARE, NSF SBIR. See docs/grants.md
